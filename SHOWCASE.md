## Engineering signals

The repository demonstrates:

* Network telemetry processing
* Packet capture with TShark and PyShark
* Kafka event transport
* Hybrid ML decision logic
* XGBoost, CNN LSTM, and DQN integration
* Deception and honeypot workflows
* Security event persistence
* Administrative security workflows
* Explicit threat modelling
* Responsible research boundaries
* Continuous integration and repository hygiene checks

## Review note

The project deliberately separates validated implementation behavior from experimental or research claims. That distinction is documented in the security and evaluation documents.
