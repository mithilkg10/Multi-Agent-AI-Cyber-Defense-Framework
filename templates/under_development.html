Roadmap & Next Steps
Milestones & Timeline
Objective 1 — Completed
Implemented a real-time anomaly detection pipeline using hybrid ML: XGBoost (tabular features) + CNN-LSTM (temporal patterns), integrated into the ingestion flow.
Objective 2 — Completed
Developed and integrated the DQN-based decision engine that maps anomaly scores and context to actions (Allow / Watch / Block / Redirect).
Objective 3 — Completed
Deployed adaptive deception layer (honeypot) on a separate service; honeypot logs attacker behaviour and provides labeled samples for analysis.
Objective 4 — In progress (Primary remaining)
Build safe continuous learning loop that periodically retrains ML and RL models using validated honeypot captures. Tasks: data curation, validation gates, training pipeline, and canary rollout.
Frontend polish & UX improvements
Polish dashboard visual elements, fix UI routing, ensure responsive layout, and improve clarity on threat action (BLOCK / REDIRECT / WATCH).
Testing & Deployment
Complete end-to-end testing (integration, performance), package the services, and deploy (CI/CD and hardening). Ensure monitoring & rollback strategy for model updates.
